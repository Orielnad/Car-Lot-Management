# עקרונות ממשק, RTL ומילון מונחים

מבוסס במלואו על סעיף 27 במסמך האפיון: "מערכת פשוטה לעובדי Excel". פשטות הממשק היא
דרישת ליבה, לא שיפור עתידי — ראו גם `CLAUDE.md`.

## עקרון-על
עובד עם ידע בסיסי ב-Excel צריך להצליח להוסיף לקוח, לאתר רכב, לקבוע משימת חזרה ולפתוח
עסקה — אחרי הדרכה של עד 30 דקות.

## ניווט ראשי (מצומצם בכוונה)
דף הבית · רכבים · לקוחות · משימות · עסקאות · מסמכים.
כלי ניהול, אוטומציות, כספים, דוחות, ספקים והרשאות מוצגים רק למי שמורשה — לא מעמיסים על
התפריט של העובד הרגיל.

## רכיבי יסוד ל-MVP
| רכיב | דרישה |
|---|---|
| DataTable | עמודות/שורות כמו Excel; מיון בלחיצה על כותרת; הקפאת כותרת; חיפוש בולט; עריכה מהירה של שדות בטוחים בלבד |
| Wizard (אשף) | מספר קטן של שדות בכל שלב; שמירה אוטומטית בין שלבים; אפשרות להמשיך מאוחר יותר |
| StatusBadge | צבע **תמיד** מלווה בטקסט — אף פעם לא צבע בלבד |
| GlobalSearch | חיפוש אחד לפי מספר רישוי / VIN / שם / טלפון / מסמך, ללא בחירת מודול מראש |
| Toast / הודעת מערכת | שפה ידידותית ("נשמר בהצלחה"), לעולם לא קוד שגיאה טכני |
| EmptyState | הסבר + כפתור פעולה, לא מסך ריק סתם |
| LoadingState / ErrorState / NoPermissionState | חובה לכל מסך; שגיאה = אפשרות ניסיון חוזר |

## RTL ועברית
- כיווניות מלאה מימין לשמאל בכל רכיב, כולל טפסים, טבלאות, תאריכים ומספרים.
- שפה פשוטה, ללא מונחים טכניים שאינם נחוצים.
- כפתור = פועל ברור ("שמור", "חזור ללקוח", "שלח הצעה"), לא רק אייקון.
- ניווט מקלדת מלא וסדר Tab הגיוני; תמיכה בהגדלת ממשק עד 200% בלי אובדן מידע.

## מילון מונחים (חובה להשתמש בעברית שבטור הימני בממשק המשתמש)
| מונח מקצועי פנימי (קוד/DB) | כיתוב שיוצג לעובד |
|---|---|
| Lead | לקוח מתעניין |
| Pipeline | שלבי המכירה |
| Follow-up | לחזור ללקוח |
| Inventory Aging | ימים במלאי |
| Conversion | פניות שהפכו למכירות |
| Workflow | תהליך עבודה |
| Dashboard | מסך ראשי |
| SLA | זמן יעד לטיפול |

בקוד המקור (משתנים, טבלאות, endpoints) ממשיכים להשתמש במונחים באנגלית מהטבלה — התרגום
קורה רק בשכבת התצוגה, כדי שהמונחים הטכניים יישארו עקביים וקריאים למפתחים.

## הודעות מערכת סלחניות
- הודעת שגיאה מסבירה מה חסר ואיך לתקן, לדוגמה: "חסר מחיר רכישה. יש להזין אותו לפני
  העברת הרכב למכירה" — לא "Error 400".
- פעולה בלתי הפיכה מציגה את המשמעות בשפה ברורה לפני ביצוע.
- ניתוק אינטרנט זמני לא מוחק טופס פתוח — נשמר מקומית וממתין לסנכרון.
